# VLSI Design Internship – Task 3

## Sequential Circuit Design and Simulation

This task focuses on the design and simulation of basic sequential circuits using Verilog HDL and Vivado.

## Circuits Implemented

1. D Flip-Flop
2. JK Flip-Flop
3. 4-bit Register
4. 4-bit Binary Counter

## Tools Used

- Verilog HDL
- Xilinx Vivado
- Behavioral Simulation

## Verification

Each circuit was implemented using Verilog HDL and verified through behavioral simulation using dedicated testbenches.

Simulation waveforms are included for each design.
